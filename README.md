# 👨‍💻 About Me

I am an **English-educated Computer Engineering graduate** with a strong technical foundation in **software engineering, computer systems, networking, infrastructure, and cybersecurity**.

My professional interests are centered around understanding how complex systems are designed, how they communicate, how they fail, how vulnerabilities can be identified, and how secure and scalable architectures can be built.

My primary technical focus is:

> **Cybersecurity × Software Engineering × Systems × Networking × Cloud**

I enjoy working across the boundaries between development and security rather than treating them as completely separate disciplines.

My approach combines:

- Software development
- System architecture
- Network engineering
- Infrastructure
- Cybersecurity
- Cloud technologies
- Automation
- Security analysis
- Digital transformation

I am also the **Founder of YMN Solutions**, a technology-focused company working across software development, IT consulting, cybersecurity, cloud infrastructure, and digital transformation.
